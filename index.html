Swipe through the designs and approve, reject, or comment.

✔️ Open the review app

Works on any phone · nothing to install or sign into

For the designer

  1. Open the designs folder in this repository.
  2. Click Add file → Upload files and drop the images in.
  3. Commit. They appear in the review app within a few minutes.

Filenames become the titles, so name them like 01-passport-inside.png. Optional: edit designs/manifest.json to add descriptions.
